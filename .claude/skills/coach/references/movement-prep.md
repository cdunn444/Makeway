# Movement Prep

Every training day's brief includes a movement prep block: 5–10 minutes of
activation/mobility matched to the session, plus 2–3 prehab exercises if the user has
logged injuries. Keep it short enough to actually get done — three to five items, with
reps/time, one line each. Offer form cues on request.

## By session type

### Running — easy
- 2–3 min brisk walk or very easy jog into the run
- Leg swings, front-back and side-side — 10/leg
- Walking lunge with reach — 6/leg

### Running — quality (tempo, intervals) 
- 5 min easy jog
- Leg swings 10/leg + hip circles
- A-skips 2×20 m, high knees 2×20 m
- 3–4 strides (15–20 s builds to ~90% effort) before the first hard rep

### Running — long run
- Same as easy-run prep; add calf raises 2×15 and glute bridge 2×10 if morning run
  (stiff-from-sleep tissue)

### Strength — lower
- 3–5 min easy cardio (bike, row, brisk walk)
- Bodyweight squat 2×10, glute bridge 2×10
- World's greatest stretch — 3/side
- Empty-bar or light warm-up sets of the first main lift (2–3 ramping sets)

### Strength — upper
- Band pull-aparts 2×15, scap push-ups 2×10
- Arm circles + thoracic rotations — 8/side
- Light ramping sets of the first press/pull

### Rest / active recovery
- Optional 10-min mobility flow: hip flexor stretch, pigeon or figure-4, thoracic
  opener, calf stretch — 60–90 s each. Frame as optional, never as a workout.

## Prehab menus by reported issue

Pick 2–3, appended to the day's prep. These are conservative, commonly prescribed
patterns — if symptoms are acute, worsening, or undiagnosed, recommend a professional
evaluation instead of programming around it.

| Issue | Prehab staples |
|---|---|
| Knee (patellar/PFP) | Step-downs 3×8/leg, terminal knee extensions 2×15, wall sit 2×30–45 s; avoid deep loaded flexion while irritated |
| Achilles / calf | Eccentric heel drops 3×12/leg (straight + bent knee), isometric calf hold 3×30 s |
| Plantar fascia | Big-toe/calf stretch 2×45 s, foot rolling 1–2 min, short-foot doming 2×10 |
| Low back | Bird-dog 2×8/side, dead bug 2×8/side, glute bridge 2×12; brace before hinging |
| Hip / glute (incl. IT band) | Side-lying hip abduction 2×12, monster walks 2×15 steps, single-leg balance 2×30 s |
| Shoulder | Band external rotations 2×15, face pulls or band pull-aparts 2×15, scap push-ups 2×10 |
| Hamstring | Isometric hamstring bridge 3×20 s progressing to sliders/eccentrics 2×8, avoid sprint work until symptom-free |
| Ankle (post-sprain) | Single-leg balance 2×30 s (progress: eyes closed), ankle alphabet, banded dorsiflexion 2×15 |

**Pain vs. soreness rule (repeat it to users):** mild pulling/working sensation up to
~3/10 that settles after the session is acceptable in rehab work; sharp pain, joint
pain, or anything that worsens during/after means stop and adjust.
