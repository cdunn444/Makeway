# coach-data

Your personal coach state lives here — created and maintained by the `/coach` skill.

- `profile.json` — goals, stats, injuries, dietary preferences, schedule, macro targets
- `plan.json` — your current training plan
- `log.jsonl` — every logged workout, nutrition check-in, weigh-in, and adaptation
- `notes.md` — the coach's free-form memory

These files are plain text and yours to read or edit by hand. If this repo is shared
and you'd rather keep them private, add `coach-data/*.json`, `coach-data/*.jsonl`,
and `coach-data/notes.md` to `.gitignore`.
